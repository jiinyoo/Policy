본 앱은 위에 명시된 Google AdMob 외에 어떠한 제3자에게도 사용자 정보를 제공하지 않습니다.

### 4. 아동의 개인정보

본 앱은 만 13세 미만의 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
